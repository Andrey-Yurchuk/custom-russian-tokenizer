# Custom Russian Tokenizer: BPE-токенизатор для русского языка с нуля

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Andrey-Yurchuk/custom-russian-tokenizer/blob/main/notebooks/custom_russian_tokenizer.ipynb)

Собственный BPE-токенизатор, обученный на русской части корпуса `Helsinki-NLP/opus_books`, и его сравнение с промышленными
токенизаторами `cointegrated/rubert-tiny2` и `DeepPavlov/rubert-base-cased`: пословные разбиения, анализ русской морфологии,
метрики (токенов на слово, `[UNK]`) и эксперименты с размером словаря, объёмом корпуса и токенизаторами LLM.

Весь код, результаты и выводы - в ноутбуке [`notebooks/custom_russian_tokenizer.ipynb`](notebooks/custom_russian_tokenizer.ipynb).
Обученный токенизатор - [`tokenizer/ru_bpe.json`](tokenizer/ru_bpe.json).

## Результаты

Среднее число токенов на слово (меньше - лучше; последовательности короче, в контекстное окно модели влезает больше текста):

| Токенизатор | Словарь | Тестовые предложения (современный язык) | Отложенная выборка (та же книга) |
|---|---|---|---|
| **Наш BPE** | 16 000 | 2.78 | **1.23** |
| rubert-tiny2 | 83 828 | 1.82 | 1.22 |
| rubert-base-cased | 119 547 | **1.72** | 1.22 |

Примеры разбиений:

| Слово | Наш BPE | rubert-base-cased |
|---|---|---|
| передумать | `пере ##думать` | `передум ##ать` |
| недопонятого | `недо ##по ##нятого` | `недоп ##он ##ято ##го` |
| железнодорожный | `железнодоро ##жный` | `железнодорожный` |
| смартфон | `с ##ма ##рт ##ф ##он` | `смартфон` |
| кринж | `кри ##н ##ж` | `кри ##н ##ж` |
| Аркадьич | `Аркадьич` | `Аркад ##ьи ##ч` |

## Ключевые наблюдения

- **Токенизатор хорош на «своих» текстах.** На предложениях из той же книги словарь на 16 тыс. токенов работает на уровне RuBERT
  со словарями на 84 и 120 тыс. На современном тексте (сленг, заимствования, составные слова) он режет слова в 1.5–1.6 раза мельче:
  в корпусе - по сути одна книга, «Анна Каренина», и таких слов в ней нет.
- **Морфологию BPE выучил интуитивно.** Все проверенные приставки (`пере`, `под`, `недо`, `раз`…) и большинство окончаний
  (`##ая`, `##ые`, `##ами`, `##ать`) есть в словаре, потому что это самые частые кусочки русских слов. Но `##ого` нет: BPE склеивает
  пары жадно, и гласная окончания «прилипает» к предыдущей согласной (`##ного`, `##кого`, `##ского`).
- **`[UNK]` возникает из-за неизвестного символа, а не слова.** В корпусе нет `ё`, тире `—`, кавычек `«»`, `№`; их пришлось добавить
  нормализатором (`ё` → `е`) и через `initial_alphabet`. У `rubert-tiny2` нет в словаре тире `—`: 561 `[UNK]` на отложенной выборке.
- **Размер словаря ограничен корпусом.** При `min_frequency=2` корпус даёт максимум ~24.6 тыс. токенов. Рост словаря помогает
  на тексте книги (8 тыс. → 24.6 тыс.: 1.36 → 1.18 токена на слово), но почти не помогает на современных словах (2.90 → 2.73).
- **Разнообразие корпуса важнее объёма.** Русская сторона всех шести пар `opus_books` (в 1.8 раза больше текста, но похожие книги)
  при том же словаре почти ничего не дала (2.75 против 2.78).
- **Токенизатор определяет «стоимость» текста в LLM.** Одно и то же предложение у GPT-2 занимает 11 токенов на английском и 96
  на русском, у многоязычного Qwen2.5 - 11 и 33.

## Пайплайн

1. Загрузка `Helsinki-NLP/opus_books`, пара `en-ru`, русская сторона: 17 496 предложений.
2. Очистка: Unicode NFC, `--` → `—`, нормализация многоточий, удаление заголовков глав и пустых строк (17 257 предложений).
3. Отложенная выборка 5% для честной проверки, генератор батчей для `train_from_iterator`.
4. BPE-токенизатор (`tokenizers`): нормализатор NFC + `ё` → `е`; pre-tokenizer: пробелы, изоляция пунктуации, цифры по одной;
   `vocab_size=16 000`, `min_frequency=2`, спецтокены `[PAD] [UNK] [CLS] [SEP] [MASK]`; post-processor `[CLS] … [SEP]`.
5. Пословное сравнение с RuBERT на 8 трудных предложениях: морфология, составные слова, сленг, заимствования, редкие имена и символы.
6. Анализ морфологии: приставки и окончания в словаре, однокоренные слова, склонение, удачные и неудачные разбиения.
7. Метрики: токенов на слово, доля слов целиком, доля однобуквенных кусочков, `[UNK]` с поиском символов-виновников.
8. Эксперименты: `vocab_size` 8 / 16 / 32 тыс., объединённый корпус из всех пар с русским, токенизаторы GPT-2 и Qwen2.5.

## Использование готового токенизатора

```python
from tokenizers import Tokenizer

tokenizer = Tokenizer.from_file('tokenizer/ru_bpe.json')
encoding = tokenizer.encode('Левин перечитал письмо и улыбнулся.', add_special_tokens=False)

print(encoding.tokens)  # ['Левин', 'перечитал', 'письмо', 'и', 'улыбнулся', '.']
print(encoding.ids)
print(tokenizer.decode(encoding.ids))
```

Обучение BPE в библиотеке `tokenizers` не полностью воспроизводимо: при равной частоте пар порядок слияний может отличаться
между запусками, поэтому id токенов и несколько самых редких токенов меняются, а разбиение слов и метрики остаются прежними.
Файл в репозитории соответствует сохранённым в ноутбуке результатам.
